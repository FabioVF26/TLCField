# Sviluppo 0.7

La versione 0.7 collega il modulo KAIROS alla scheda di intervento.

Dati KAIROS registrabili:
- Input Supply Voltage [V]
- TX Temperature [°C]
- Forward Power [W]
- Reflected Power [W]
- RSSI Main [dBm]
- RSSI Diversity [dBm]
- sorgente/stato di sincronizzazione

Per ogni allarme scelto vengono riportati significato, soglie disponibili e checklist. Solo le verifiche marcate dal tecnico vengono salvate come eseguite e riportate nel PDF.

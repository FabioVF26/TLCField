# Note dati iniziali

I dati del prototipo derivano dalle schede tecniche fornite dall'utente. Non sono state effettuate correzioni autonome dei dati di origine.

In particolare, le coordinate di "Monte Cavo Alto" sono state mantenute come riportate nella scheda ma contrassegnate come **da verificare**, per evitare che il pulsante di navigazione conduca a una posizione potenzialmente errata.
